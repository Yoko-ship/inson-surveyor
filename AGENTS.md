# Repository work instructions

- Maintain `WORK_LOG.md` as requested by the user. Update it as meaningful changes are made, checks finish, or blockers/scope change; do not wait until the final response.
- Distinguish completed work, work in progress, validation evidence and external dependencies. Record failures and their resolution accurately.
- Never include secrets, customer data, authentication material or private documents in the work log.
- Keep functional browser testing headless/in the background unless the user explicitly requests a visible window.
